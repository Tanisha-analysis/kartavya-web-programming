# KARTAVYA – Civic Support Web Application

**Empowering People. Connecting Communities. Creating Change.**

## About the Project
KARTAVYA is a civic support web application developed as part of an academic Web Programming project. It aims to connect people with community support, encourage the reuse of useful items, and provide a platform for raising civic concerns.

The project focuses on creating a simple, accessible, and user-friendly web interface using front-end web technologies.

## Features
### 1. Help Connect
Provides a section for connecting people who need assistance with people who may be able to help.

### 2. Share & Reuse
Encourages users to share reusable items and reduce waste by giving useful belongings a second life.

### 3. Civic Voice
Provides a section for expressing civic concerns and highlighting community issues.

## Technologies Used
- **HTML5** – Web page structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through the available sections of the application.

No additional installation is required for a basic front-end project.
